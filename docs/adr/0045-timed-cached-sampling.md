# 0045 按持续时长采样 C ABI 内存

日期：2026-10-30。状态：实施决定；实测结果另行记录。

已有固定轮次回归无法回答持续数分钟运行时的表现。本轮新增独立开发工具，在单个 C 测量进程中持续调用默认缓存采集器，每次检查 Buffer 并释放。使用单调时钟，每完成一次调用后请求休眠 100 ms，每 60 秒记录当前驻留值、历史峰值、累计调用数及最大 JSON 长度。不承诺精确调用频率；另设每秒 20 次的总量上限。

支持 120–3600 秒、60 秒的整数倍。120–540 秒试验热身 60 秒；600 秒及以上热身 300 秒。事前固定热身后采样的最大值减最小值预算为 16 MiB，不按结果调整。CI 运行 120 秒，本机先运行 600 秒；不能把它们当作小时／天级或无泄漏证据。

复用现有进程峰值、当前驻留值与独立 64 MiB 校准，保留 Linux 的薄 C launcher/fork 隔离和父退出清理。休眠使用 [Windows Sleep](https://learn.microsoft.com/en-us/windows/win32/api/synchapi/nf-synchapi-sleep) 与 POSIX nanosleep；发生 EINTR 时继续剩余等待。睡眠与调度不保证精确间隔，因此报告实际调用数与时间。暂停、休眠或过度调度延迟可能使试验失败，应保留失败原因，而不是当作泄漏结论。

每分钟观测以有界 NDJSON 写出并刷新，结束必须有完成标记。检查点缺失/乱序、时间不符、计数或单位错误、输出超限、调用失败、预算超限均不能接受。Linux launcher 在计划时长加 30 秒后到期，Python 调用等待上限为计划时长加 60 秒；失败/中断作废旧通过报告并保留已有检查点。C 测量程序与共享库保持加载至进程结束，不卸载热重载。

报告绑定干净提交、锁定工具链、编译器、机器摘要与三个二进制哈希，结束再核对源码及二进制。默认隐私；不保存硬件完整快照或序列号。当前驻留受共享页、allocator、工作集调整和采样间隔影响；一分钟采样不能排除间隔内峰值，也不能用于 allocator 归因。历史峰值同时保留，不能拿两种指标互换。

仅开发探针与验收脚本变化；正式 Rust API、C ABI 1、硬件 Schema 1、依赖、features、MIT 不变。新 NDJSON 为独立私有格式 1，原固定轮次探针格式 2 不变。回退可移除定时模式、工具及 CI 步骤，保留旧回归和证据。
