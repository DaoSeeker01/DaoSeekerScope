# 0004 C ABI v1 / JSON Schema v1

固定符号：dsc_abi_version、dsc_collect_json、dsc_buffer_free、dsc_last_error。不暴露 Rust 模型。options 为版本化固定宽度 C struct（size/version/flags/timeout_ms/max_entries）；未知 flags/version/大小拒绝。flags bit0 请求敏感数据、bit1 声明调用方已获授权。均未设置时默认不采集。传递 null options 使用默认。

Buffer={const uint8_t *data; size_t len; uint64_t token;}；库分配、非 NUL UTF-8 JSON；C 必须按 len 读取并调用 free。库的有界注册表保留 Arc<[u8]>，通过 Arc::as_ptr 导出只读指针；移动条目或扩容不能改变共享所有权。token 单调不复用，释放核对 token+地址+长度，不 dereference 输入数据指针，重复释放（包括陈旧复制）拒绝。成功 free 将原 struct 清零；同一 struct 重复 free 空值成功。最多64个未释放 buffer，单 buffer ≤1MiB。调用方不得复制后并发释放/使用；不得传无效 struct 指针，库无法验证任意 C 地址。函数 unsafe 的要求在头文件和 Rust Safety 文档中明确。

所有边界 catch_unwind，panic=unwind 构建；abort/OOM/非法 C 指针不能捕获，不声称绝对无进程故障。状态码固定：0 OK、1 invalid argument、2 unsupported platform、3 timeout、4 cancelled、5 busy、6 backend failure、7 resource limit、8 panic、9 invalid buffer。dsc_last_error 返回固定文本的线程局部 buffer，生命周期至本线程下一次 ABI 调用；不包含路径/设备标识。线程可并行调用不同 output struct。ABI 主版本变更必须添加迁移文档和并存符号策略。

Schema 从同一强类型通过 schemars 生成，黄金样例确定性 fake backend，默认 unknown JSON fields 忽略、未知枚举和违反 Observed 不变量拒绝。Python ctypes 和 C 最小程序验证 buffer 生命周期；CLI 全部走门面，不另写采集算法。仅提供 options 契约和 header 时不算 ABI 实现完成。

2026-10-09 实现修订：Miri发现先导出Box数据指针、后移动Box到注册表，Unique retag使旧指针读取无效。改用Arc共享所有权，不改变ABI/Schema。回归覆盖读取、扩容、并发独立buffer和释放；只测释放不足以验证该契约。见 [输入与FFI验证](../input-ffi-validation.md)。

2026-10-11 契约补充：NULL options 复用默认采集器，非 NULL options 每次创建独立采集器，不跨调用缓存静态值或 CPU 基线。JSON 输入展开后的完整编码也必须不超过 1 MiB；过限返回 ResourceLimit。现有布局、符号和 ABI/Schema 主版本保持 1，见[检查报告](../project-review-2026-10-11.md)。

共享库生命周期：默认采集器持有常驻 worker，超时的原生调用也可能继续运行；ABI v1 不提供 shutdown/排空接口。调用方须在任何采集调用后（包括失败或超时）保持库加载至进程结束。本版不支持动态卸载/热重载，释放所有 Buffer 不证明 worker 已结束。支持卸载需要另行设计生命周期和可终止平台边界，不能通过强杀线程补充。2026-10-29 已同步安装头文件与 Rust 文档，见 [ADR 0042](0042-release-contract.md)。
