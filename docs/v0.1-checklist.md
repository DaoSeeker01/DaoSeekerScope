# v0.1 交付清单

当前版本为 0.1.0 开发版，未正式发布。本清单区分首版交付门槛、可后续增强的能力和延期设备测试；没有把剩余工作换算为缺乏依据的百分比。

| ID | 交付项 | 当前状态与依据 |
|---|---|---|
| V01-01 | Rust、CLI、JSON、C ABI 的桌面最小闭环 | 已有三平台原生 CI、C/Python 和八包验收；见 [Linux SDK 验收](linux-ffi-sdk-validation.md) |
| V01-02 | 能力、状态、来源、隐私和刷新契约 | 已实现；零尺寸隔离与本轮三平台回归已通过；见 [审计](project-review-2026-10-27.md) |
| V01-03 | README、贡献、安全、社区、模板和更新日志 | 社区文件、YAML 表单及文档检查通过；私密报告已开启 |
| V01-04 | 打包失败不会遗留旧成功报告 | 失败/中断作废与来源绑定已修复，本机和三平台独立八包回归通过 |
| V01-05 | Windows/Linux CLI 与 SDK 的候选安装和回滚 | 本轮两平台候选回归通过；候选不是正式分发 |

| V01-07 | 最低 OS、glibc/系统依赖及架构范围 | Windows PE、Linux 符号版本及[较低版本用户空间测试](linux-runtime-container-validation.md)已验收；当前候选已在固定 [glibc 2.34 与 2.36 用户空间](linux-glibc234-validation.md)正常运行，2.31 被拒绝。最低内核、所有同版本 glibc 安装及完整平台范围仍待验证 |

| V01-09 | 长期 fuzz、峰值内存与更广故障验证 | 短 fuzz、Miri/ASan、耗时与[三平台峰值、固定轮次驻留回归与启动隔离](benchmarks.md)及[本机 10 分钟、CI 2 分钟定时试验](timed-soak-validation.md)已有证据；长期 fuzz、小时／天级内存验证及更多故障覆盖待完成 |
| V01-10 | 正式发布 | 未授权、未执行；发布步骤见[发布路线](release.md) |

首版不承诺所有硬件字段均可用。更多 GPU 来源、其他平台电池/传感器、显示器名称与像素扩展按[开发进度](progress.md)逐项验收；现有字段保留真实限制。

维护者目前缺少实体 Linux/macOS 与多处理器组硬件，相应真机验证按已有安排延期。CI、容器和合成输入分别记录，不能替代这些设备证据。Android/iOS/Web/no_std/MCU 是独立后续阶段。

旧正式版升级路径要等实际旧版存在后验证；当前两槽位演练只证明同候选目录切换。正式发布前应明确首版不适用项及后续升级承诺。
