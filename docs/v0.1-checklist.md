| ID | 交付项 | 当前状态与依据 |
|---|---|---|

| V01-02 | 能力、状态、来源、隐私和刷新契约 | 已实现；零尺寸隔离与本轮三平台回归已通过；见 [审计](project-review-2026-10-27.md) |
| V01-03 | README、贡献、安全、社区、模板和更新日志 | 社区文件、YAML 表单及文档检查通过；私密报告已开启 |
| V01-04 | 打包失败不会遗留旧成功报告 | 失败/中断作废与来源绑定已修复，本机和三平台独立八包回归通过 |

| V01-10 | 正式发布 | 未授权、未执行；发布步骤见[发布路线](release.md) |

首版不承诺所有硬件字段均可用。更多 GPU 来源、其他平台电池/传感器、显示器名称与像素扩展按[开发进度](progress.md)逐项验收；现有字段保留真实限制。

维护者目前缺少实体 Linux/macOS 与多处理器组硬件，相应真机验证按已有安排延期。CI、容器和合成输入分别记录，不能替代这些设备证据。Android/iOS/Web/no_std/MCU 是独立后续阶段。

旧正式版升级路径要等实际旧版存在后验证；当前两槽位演练只证明同候选目录切换。正式发布前应明确首版不适用项及后续升级承诺。
